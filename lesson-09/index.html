Code Night — ночь, когда студенты создают будущее

12 часов, одна команда и ни одной готовой идеи. Собирайся с друзьями, придумывай проект, пиши код и представляй его утром.

Никаких «завтра» — только то, что ты успеешь сделать этой ночью.

3 шага до рассвета

  • THINK (Подумай): Придумай идею, которая стоит бессонной ночи, и собери команду от 3 человек.
  • CODE (Кодируй): 12 часов чистого времени на разработку, дизайн и сборку твоего проекта.
  • SHIP (Защити): Утром покажи результат экспертам и другим участникам хакатона.

Кто делает Code Night

Мы — студенты, которые устали от скучных лекций и решили, что лучший способ учиться — это делать реальные проекты. Code Night создан для тех, кто хочет проверить свои силы в веб-разработке, дизайне или управлении проектами.

Это не просто соревнование, а возможность найти единомышленников, получить обратную связь от опытных наставников и добавить в портфолио кейс, который ты сделал за одну ночь. Опыт не важен — важна твоя идея и желание её реализовать.
